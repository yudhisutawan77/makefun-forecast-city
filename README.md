Entry for the [make.fun bounty "Funniest Forecast for a City That Isn't"](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf) — one line, at most 120 characters, the funniest weather forecast for a city that does not exist.

## The entry

> Quibbleton: fog so thick locals voted it mayor. Visibility 3 metres, turnout 98%, regret 100%.

94 characters, 94 bytes, one line.

## How it works

`main.py` writes the single forecast line to `/output/entry.txt` (or wherever the grader points it via `ENTRY_OUT` / `MAKEFUN_OUTPUT_DIR`). No trailing newline.
